# Fibonacci Series

A simple Python program that generates the Fibonacci series for a given number of terms.

## Features

- Generates the Fibonacci series.
- Takes the number of terms as input from the user.
- Uses basic Python programming concepts.
- No external packages are required.

## Requirements

- Python 3.x

## Usage

Run the program using:

```bash
python fibonacci.pyEnter the number of terms: 7
Fibonacci series:
